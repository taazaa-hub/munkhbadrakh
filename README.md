# Мөнхбадрах ОСК — Төлбөрийн вэбсайт

## Файлууд
- `index.html` — Айлууд утасны дугаараараа сар бүрийн төлбөр/төлөлт/үлдэгдлээ хардаг нүүр хуудас
- `admin.html` — `"нэгтгэл"` sheet бүхий Excel файл upload хийдэг admin хуудас
- `config.js` — Supabase холболтын тохиргоо
- `setup.sql` — Supabase дээр нэг удаа ажиллуулах хүснэгт үүсгэх скрипт (`toot_tolbor`)
- `import_2026_01_08.sql` — `УС ДУЛААНЫ ТӨЛБӨР 2026.xlsx` файлын `"нэгтгэл"` sheet-ээс гаргасан 2026 оны 1-8 сарын дата
- `import_2026_08_zadargaa.sql` — `Zadargaa 8 sAR.xlsx` файлын 8-р сарын ус/дулааны дэлгэрэнгүй задаргаа

## Excel файл оруулах (admin.html)

`admin.html`-ийн эхний карт нь **файлын төрлийг өөрөө таньдаг**. Sheet-ийн нэр,
толгойн мөрийн байрлал, баганын дараалал өөр байсан ч ажиллана:

| Файл | Танигдах шинж | Юу болох вэ |
|---|---|---|
| `Zadargaa 8 sAR.xlsx`, `6 сар.xlsx`, `7 сар.xlsx` … | "Тоот", "Суурь хураамж", "Хүйтэн", "Халуун", "Бохир ус", "Нийт усны төлбөр", "Суурь үнэ", "ДУЛААНЫ ТӨЛБӨР m2", "ХАЛУУН УСНЫ ТООЛУУР", "Нийт дүн", "Нийт төлбөр" толгойтой sheet | Тухайн сарын **тоолуурын задаргаа**-г бичнэ |
| `УС ДУЛААНЫ ТӨЛБӨР 2026.xlsx` | "Тоот" болон "1-р сар" / "6 сар" мэтийн сарын толгойтой sheet (`нэгтгэл`) | Сар бүрийн **Төлбөр / Төлөлт / Үлдэгдэл**-ийг бичнэ |

**Он, сар** талбарт:
- `2026-08` — тухайн нэг сарыг оруулна (задаргааны файлд ЗААВАЛ ийм байх ёстой)
- `2026` — нэгтгэл файлын бүх сарыг нэг дор оруулна

Хамгаалалтууд:
- `Sheet1`, `нэгтгэл` гэх мэт **нэрээр sheet сонгохоо болисон** — бүх sheet-ийг
  шалгаж бүтцээр нь олдог тул `УС ДУЛААНЫ ТӨЛБӨР 2026.xlsx` доторх хоосон
  `Sheet1`-д хууртахаа больсон.
- `12 сарын үлдэгдэл` баганыг "12-р сар" гэж андуурахгүй.
- Тухайн сарын Төлбөр ба Төлөлт хоёулаа хоосон бол тэр мөрийг **алгасна** —
  ингэснээр хоосон сарын багана задаргаанаас орсон бодит дүнг устгахгүй.
- Файлд байхгүй багана (жишээ нь задаргаанд "Овог" байхгүй) payload-д огт
  явахгүй тул өмнө орсон утга дарагдахгүй.

## Хүснэгтийн бүтэц

`index.html` ба `admin.html` хоёр `water_bills` хүснэгттэй ажилладаг.
Supabase SQL Editor дээр **`setup_water_bills.sql`**-ийг нэг удаа ажиллуулж,
шаардлагатай бүх багана байгаа эсэхийг баталгаажуулна (дахин ажиллуулж болно).

> Доорх `setup.sql`, `import_2026_01_08.sql`, `import_2026_08_zadargaa.sql`
> файлууд нь `toot_tolbor` / `toot_zadargaa` гэсэн **өөр хувилбарын** бүтэцтэй.
> Одоогийн `index.html`/`admin.html` тэдгээрийг УНШДАГГҮЙ тул хольж
> ажиллуулахгүй байхыг анхаарна уу.

## Өгөгдлийн загвар
`toot_tolbor` хүснэгтэд тоот бүрийн сар бүрийн мэдээлэл хадгалагдана:
- Тухайн сарын төлбөр (`tolbor`)
- Тухайн сарын төлсөн дүн (`tololt`)
- Тухайн сарын үлдэгдэл (`uldegdel`)
- Нийт төлөлт (`niit_tololt`)
- Овог/нэр, орц, давхар, регистр, ҮХХ №, утас, тайлбар, email

`toot_zadargaa` хүснэгтэд 8-р сарын ус/дулааны дэлгэрэнгүй задаргаа хадгалагдана:
- Усны суурь хураамж, хүйтэн/халуун усны өмнөх/одоогийн заалт, зөрүү
- Бохир ус, нийт усны төлбөр
- Дулааны суурь, дулааны m2 төлбөр, халуун усны тоолуур, дулааны нийт төлбөр

## Тохируулах алхмууд

**1. Хүснэгт үүсгэх**
Supabase project → **SQL Editor** → `setup.sql` файлын агуулгыг бүхэлд нь paste хийгээд **Run** дарна.

**2. 2026 оны 1-8 сарын датаг оруулах**
SQL Editor дээр `import_2026_01_08.sql` файлын агуулгыг бүхэлд нь paste хийгээд **Run** дарна.

Энэ import нь `2026-01`-ээс `2026-08` хүртэлх хуучин мөрүүдийг устгаад, Excel-ийн `"нэгтгэл"` sheet-ээс гаргасан шинэ датаг бичнэ.

**3. 2026 оны 8-р сарын задаргааг оруулах**
SQL Editor дээр `import_2026_08_zadargaa.sql` файлын агуулгыг бүхэлд нь paste хийгээд **Run** дарна.

Энэ import нь `2026-08` сарын задаргааг `toot_zadargaa` хүснэгтэд бичнэ. Вэб дээр `2026-08` сонгоход "Ус, дулааны төлбөрийн задаргаа" хүснэгт автоматаар харагдана.

**4. Вэб файлуудыг байрлуулах**
`index.html`, `admin.html`, `config.js` гурвыг нэг фолдерт static hosting дээр байршуулна.

**5. Айлууд харах**
`index.html`-руу орж:
- Сараа сонгоно (`2026-01` ... `2026-08`)
- Утасны дугаараа бичнэ
- `"Төлбөр харах"` дарна

**6. Дараагийн шинэ Excel upload хийх**
`admin.html`-руу орж:
- Нэвтрэх кодоо оруулна
- Оноо бичнэ (`2026`)
- `"нэгтгэл"` sheet-тэй Excel файлаа сонгоно
- `"Оруулах"` дарна

Admin upload нь файл дотор байгаа бүх сарын баганыг (`1-р сар`, `2-р сар`, ... `8 сар`) автоматаар уншаад `toot_tolbor` хүснэгтэд upsert хийнэ.

## Аюулгүй байдлын санамж
Одоогийн тохиргоо `anon key`-г шууд ашигладаг тул `admin.html`-ийн линкийг зөвхөн итгэмжлэгдсэн хүмүүст өгнө үү.

## QPay Edge Function тохиргоо

QPay API v2 collection-ий merchant endpoint-уудтай нийцүүлж Edge Function-ууд `/v2/auth/token`, `/v2/invoice`, `/v2/payment/{payment_id}` endpoint ашиглана. Дансны мэдээллийг collection-оос биш өөрийн QPay merchant-аас авна.

`qpay-create` болон `qpay-callback` хоёр function-д Supabase secrets болгон дараах утгуудыг тохируулна: `QPAY_USERNAME`, `QPAY_PASSWORD`, `QPAY_INVOICE_CODE`, `CALLBACK_SECRET`. `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`-г Supabase өөрөө function-д өгдөг (`SUPABASE_` гэж эхэлсэн secret-ийг CLI алгасдаг). `QPAY_BASE`-г тохируулаагүй үед `https://merchant.qpay.mn` production endpoint ашиглана. Sandbox-д шалгах бол `QPAY_BASE=https://merchant-sandbox.qpay.mn` тохируулна.

Локал `.env`-ийг linked Supabase project руу sync хийхдээ `supabase secrets set --env-file .env` ажиллуулна. Энэ project-д холбохын өмнө `supabase link --project-ref <project-ref>` шаардлагатай.

Function secrets тохируулсны дараа хоёр Edge Function-ийг дахин deploy хийнэ. `setup_water_bills.sql`-ийг SQL Editor дээр ажиллуулсан байх шаардлагатай.

`qpay-callback` нь QPay-ээс шууд дуудагддаг тул JWT баталгаажуулалт унтарсан байх ёстой. Үүнийг `supabase/config.toml` дахь `[functions.qpay-callback] verify_jwt = false` тохируулдаг тул энгийнээр deploy хийнэ: `supabase functions deploy qpay-create` болон `supabase functions deploy qpay-callback`.

## Migration ба автомат deploy

- DB-ийн өөрчлөлт бүр `supabase/migrations/<timestamp>_<нэр>.sql` файлаар орно. Live DB руу `supabase db push` (эсвэл GitHub Actions) хийнэ. `setup_water_bills.sql`-ийг live DB дээр дахин бүтнээр нь ажиллуулахгүй.
- `.github/workflows/supabase-deploy.yml` нь `main` руу `supabase/` доторх өөрчлөлт push хийгдэх бүрд migration push хийж, хоёр function-ийг deploy хийнэ. Repo secrets: `SUPABASE_ACCESS_TOKEN`, `SUPABASE_DB_PASSWORD`, `SUPABASE_PROJECT_REF`.
